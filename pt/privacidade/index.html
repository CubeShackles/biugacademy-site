Aviso provisório

Privacidade

Este sítio é informativo. Não recolhe dados através de formulários e não usa testemunhos de conexão de rastreio.

Aviso provisório. A política de privacidade completa está em revisão jurídica e será publicada antes da reabertura de qualquer recolha de dados pessoais.

O que este sítio trata

As candidaturas estão encerradas e nenhuma página recolhe ou envia dados através de formulários.

O sítio não define testemunhos de conexão (cookies) nem usa ferramentas de análise ou publicidade.

O alojamento é feito pelo GitHub Pages, que regista dados técnicos de acesso, como o endereço IP, para segurança e funcionamento do serviço.

Os tipos de letra são carregados do Google Fonts, que recebe o endereço IP do seu navegador ao servir esses ficheiros.

Correio eletrónico

Se nos escrever para support@biugacademy.org, usamos a mensagem apenas para responder ao seu pedido e não a partilhamos para fins de marketing.

Não envie palavras-passe, documentos de identificação ou outros dados sensíveis no primeiro contacto.

Dados partilhados anteriormente

Para pedidos de acesso, retificação ou eliminação de dados partilhados anteriormente com a Academia, contacte support@biugacademy.org com o assunto «Privacidade».

Aviso

Alterações

Qualquer novo processo de candidatura, boletim por subscrição ou conta de utilizador só abrirá depois de um aviso de privacidade revisto e aprovado.
